## The problem

Which AI app should a beginner use? Reviews disagree, and the apps change often.

## The test

Three everyday tasks, the same words in each app, 3 fresh chats per task, all 27 runs between 22:56 and 23:05 New York time on 2026-10-16. Answer key written first.

| Task | ChatGPT (logged out) | Gemini (logged out, Flash-Lite) | Claude (incognito, Opus 5.5) |
| --- | --- | --- | --- |
| Text: move the car "by 6 pm today" (at 11 pm) | "6 pm today", 3/3 | "6 pm today", 3/3; added a reason 2/3 | "6 pm tomorrow" + why, 3/3; added "I'll need the space" 2/3 |
| Days from March 1 to April 15, 2027 (45) | correct 3/3 | 45 each time, but called it inclusive and gave 44 for the duration in 2/3 | correct 3/3 |
| One-sentence summary of a pool notice | kept all details 3/3 | kept desk hours 2/3; one run gave no pass count | "five passes" 3/3; added an unrequested line about the year 3/3 |

## Same task, Known answer, Read the extras

1. **Same task** (must). Identical request, same time of day, more than one run.
2. **Known answer** (must). Write what a good answer contains before reading any.
3. **Read the extras** (important). Note what each app changed or added: a new time, a reason, a note.

Put the context in your request (the time, when you'll send it) so no app has to guess.

## Boundary

Three short tasks, three runs each, one evening; not the same price tier; the time of day changed task one; apps update often; nothing here covers long documents, images, web search or code.
