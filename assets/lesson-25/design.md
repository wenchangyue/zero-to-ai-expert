# Lesson 25 demo design and results

Question: how do I use NotebookLM (renamed Gemini Notebook on 2026-07-16) to study from my own notes?
Product: Gemini Notebook on the web, owner's account (profile Default; plan shows "PRO"), 2026-11-03 08:45–09:55 New York time. One new notebook per run, the notes (lesson 22's 230-word fictional BIO 101 page) as the only source, chat turns in order T1→T4, then the Studio Quiz. A pilot notebook (same notes, T1 + Studio Quiz) was used to learn the interface; it is not scored. Answer key: truth.md (hash before the first chat turn).

| Turn | Result (3 notebooks) |
|---|---|
| T1 "Make me a study guide from these notes." | Chat replied that it had created a Studio report; the report covered 10/10 key items in 3/3; 1,682–2,003 words (notes: 230); beyond-the-notes markers from the preset list: none in runs 1–2, "NADP+" once in a table in run 3; C4/CAM appear only as "excluded from the exam". A wider check (words not in the notes, run after scoring) finds textbook terms in every guide: run 1 glyceraldehyde, photolytic, wavelength, photon, electron, eukaryotic; run 2 pigment, organelle, carbon fixation; run 3 glyceraldehyde, photolytic, wavelength, electron, reducing power. ChatGPT's lesson 22 guides: RuBP 3/3, ATP synthase 2/3, plus pigment, organelle, reducing power. |
| T2 "What is photorespiration, and why does it matter for C4 plants?" | 3/3 said the notes don't define/explain photorespiration, pointed to the exam-scope line, and offered web research instead of answering from outside |
| T3 quiz request | 3/3 asked where released oxygen comes from and waited; run 3's suggested reply buttons included "It comes from water" (the answer) |
| T4 "Carbon dioxide." | 3/3 "Not quite", gave water, quoted the exact notes line with a citation marker |
| Citation click (run 1, T4) | Clicking the citation number opens the notes in the source panel with the cited passage highlighted (checked after the runs) |
| Studio Quiz (default settings) | 10 multiple-choice questions in 3/3 |

Comparison (lesson 22, ChatGPT logged out, same notes, "Make me a study guide from these notes."): 1,132–1,299 words; RuBP in 3/3, ATP synthase in 2/3.
Change from truth.md: Studio quiz questions were recorded (count, question 1) but not each question's answer (the quiz is an interactive app showing one question at a time).
Limits: one page of notes on standard biology, one account (paid plan), one morning.
