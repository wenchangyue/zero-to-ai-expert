# Zero to AI Expert companion site

Public, source-linked companion pages for the YouTube channel [Zero to AI Expert](https://www.youtube.com/@ZeroToAIExpert).

- GitHub Pages: <https://wenchangyue.github.io/zero-to-ai-expert/>
- Lessons: `_lessons/`
- Lesson template: `TEMPLATE-lesson.md`
- Discovery files: `robots.txt`, `sitemap.xml`, `llms.txt`, and `llms-full.txt`

## Publication rule

Create the companion-page draft and stable URL during SEO/GEO preparation. After a private YouTube upload provides the video ID, fill the page metadata, publish the site, verify the live page and discovery files, and confirm that the YouTube description links to the canonical page exactly once. The requested video privacy setting does not change during this transaction.
